# VITALY BYSTROV APP v9

Полностью переработанная структура приложения.

- HOME, ABOUT, ПРАЙСЫ, КЛИЕНТЫ и CONTACT открываются как отдельные экраны.
- HOME больше не ведёт одной длинной прокруткой в остальные разделы.
- MODELS, PORTRAITS, STREET PHOTO и LANDSCAPE открываются на соответствующих страницах Pixieset.
- JOURNAL, TIKTOK и СОГЛАШЕНИЯ также ведут на соответствующие внешние страницы.
- Между статьями и фотоблоками добавлены аккуратные разделители.
- Изображения сохраняют полные пропорции без принудительной обрезки.

После загрузки в GitHub Pages сделайте Ctrl+F5 для очистки старого кэша.
