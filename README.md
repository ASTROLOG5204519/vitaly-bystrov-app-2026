# VITALY BYSTROV APP v4

A corrected single-page PWA prototype for GitHub Pages.

Important:
- Upload the CONTENTS of this folder to the root of the GitHub repository.
- Keep `index.html`, `manifest.json`, and `sw.js` at repository root.
- Navigation uses same-page hash anchors (`#portfolio`, `#about`, etc.), so it works under a GitHub Pages project URL.
- The client gallery code is only a demo; use Pixieset/private gallery links for real client security.
